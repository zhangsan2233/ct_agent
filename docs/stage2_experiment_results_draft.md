# 实验设计与结果（初稿）

## 1. 数据与实验设计

本研究使用公开的 CT-RATE 数据集训练部分中的胸部 CT 及其对应报告。实验数据并非诊断金标准：训练标签由原始报告自动抽取，属于弱监督标签。因此，以下结果衡量的是结构化输出质量、对报告弱标签的一致性，以及 CT-CLIP 证据在输出中是否被稳定保留，不能表述为临床诊断准确率。

从项目预先生成的 1,000 例候选清单中，按清单顺序确定性选取前 500 个可用 NIfTI 病例。每例同时具有 CT、报告印象和 8 个目标标签的报告弱标签：动脉壁钙化、肺不张、冠状动脉壁钙化、肺气肿、肺实变/密度增高、淋巴结肿大、肺纤维化后遗改变和肺结节。病例按 `train_编号` 归并为患者/检查组，使用固定随机种子 `20260718` 进行组级划分，得到 450 例训练集和 50 例患者不交叉的留出集。

CT 侧采用官方预训练权重 `CT-CLIP_v2.pt`。CT-CLIP 在本工作中完全冻结，仅对每个 NIfTI 输出上述 8 个发现的概率分数；未进行 CT-CLIP 微调。语言侧以 Qwen3.5-9B 为底座，先使用报告监督的 Stage-1 adapter，再在 450 例含 CT-CLIP 分数的紧凑 JSON 样本上继续 QLoRA 训练。Stage-2 的主要参数为：4-bit NF4 量化、LoRA rank=16、alpha=32、dropout=0.05、学习率 `5e-5`、单卡 micro-batch=1、梯度累积=16、最大序列长度=2048、训练 2 epoch；训练使用单张 RTX 4090。

留出评测在相同的 50 个病例上比较三个臂，均使用确定性生成（`do_sample=false`、最多生成 1024 token、批大小 4）：(1) Stage-1 仅报告；(2) Stage-2 去除 CT-CLIP 分数；(3) Stage-2 输入报告与 CT-CLIP 分数。前两臂用于检查架构与输入依赖；第三臂为最终融合系统。

## 2. 指标定义

JSON 有效率定义为能被解析为 JSON 对象的输出比例。弱标签一致性以 8 个标签的正类 micro-F1 计算，参考标签为报告弱标签。CT 证据字段覆盖率是输出中出现的 CT-CLIP 分数槽位数除以应出现的槽位数；数值一致性是这些输出分数与输入分数精确匹配的比例。两项 CT 指标只验证证据传递的完整性，不代表 CT-CLIP 的临床有效性。

## 3. 结果

在 50 例完全配对留出集上，三臂 JSON 有效率分别为 100.0%、76.0% 和 100.0%；相应的弱标签 micro-F1 分别为 1.000、0.000 和 0.749。Stage-2 移除 CT 输入后，12/50 个输出无法解析，且其余输出中经常出现与目标八标签不一致的模板标签。加入 CT-CLIP 后，模型恢复为目标紧凑 JSON 模式。

| 评测臂 | 有效 JSON | 弱标签 micro-F1 | CT 字段覆盖率 | CT 数值一致性 |
| --- | ---: | ---: | ---: | ---: |
| Stage-1，仅报告 | 100.0% | 1.000 | 不适用 | 不适用 |
| Stage-2，去 CT-CLIP | 76.0% | 0.000 | 不适用 | 不适用 |
| Stage-2，报告 + CT-CLIP | 100.0% | 0.749 | 100.0% | 100.0% |

Stage-2 加 CT-CLIP 的各标签 F1 分别为：动脉壁钙化 0.833、肺不张 0.783、冠状动脉壁钙化 0.632、肺气肿 0.571、肺实变/密度增高 0.788、淋巴结肿大 0.316、肺纤维化后遗改变 0.778、肺结节 0.909。较低的淋巴结肿大和肺气肿一致性提示：报告自动标签、CT-CLIP 概率与语言模型整合之间仍存在不稳定性，应优先纳入后续人工复核。

## 4. 边界与局限性

第一，500 例为可复现实验性子集，不能代表完整 CT-RATE 的分布。第二，所有监督及参考标签来自报告弱标签，而非放射科医师对影像的独立判读；因此 F1 不能解释为诊断性能。第三，Stage-1 的 1.000 F1 来自输入中包含由同一报告弱标签直接构造的分数，构成格式/泄漏对照，不应与最终系统作临床优劣比较。第四，CT 字段 100% 覆盖和数值一致性仅证明融合 adapter 读取并保留了传入证据，尚不能单独证明因果性的医学增益。第五，本实验没有开展独立外部测试、阈值校准、置信区间、显著性检验或放射科医师盲法阅片；这些应作为下一阶段的重点工作。
